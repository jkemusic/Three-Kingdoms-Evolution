# 進化三国 (進化三國)

[中文](README.md) | [English](README.en.md) | **日本語**

三国殺を遊びたいけれど、人数が集まらない? 90 人の武将、賢いコンピューター対戦相手、友達とのオンライン対戦が揃っています。

## 特長
- **90 人の武将**: すべてのスキルを実装。身分戦、百変モード、⚡ 連鎖カードに対応
- **賢い AI**: 身分を推理し、味方と連携します。手札を覗き見することはありません
- **友達と一緒に**: ルーム作成、オンライン対戦、観戦、切断後の再接続に対応
- **ランク戦**: ランク戦でポイントを貯めて、アイコン枠、エフェクト、実績を解放
- **見やすく使いやすい**: 20 種類のテーマカラー、PC・タブレット・スマホで遊べ、初心者向けチュートリアルとカード図鑑も用意
- **環境構築不要**: ダウンロードして開くだけ

## ダウンロード
**[Releases](https://github.com/jkemusic/Threekingdoms/releases)** から最新版をダウンロードしてください:

- **Windows**: `.exe` インストーラー、またはインストール不要の `.zip`
- **Mac**: `.dmg` (初回起動時は右クリック →「開く」)

## カードの画像
カード、武将、身分カードには SDXL で生成した水墨画風のイラストを使用し、枠がそれぞれ異なる 11 種類のカード面スタイルも用意しています。オンラインサーバー (<https://161.33.195.70.sslip.io/>) ではブラウザで開くだけで表示されます。

本プロジェクトには三国殺の原版アートは同梱していません (著作権があり、本プロジェクトは非営利で友人同士の利用に限ります)。ローカルで自分の画像を表示するには、メニュー「ゲーム → 素材フォルダを開く」で `三國殺牌/` と `三國殺武將卡/` に画像を入れ、再起動してください。

## 友達とオンライン対戦
メニュー「ゲーム → LAN モード」。同じネットワークの友達がブラウザで `http://<あなたの IP>:8765/` を開けば参加できます。
