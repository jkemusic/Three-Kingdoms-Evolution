# 進化三國

想玩三國殺,但湊不到人?這裡有 90 位武將、聰明的電腦對手,還能跟朋友連線一起打。

## 特色
- **90 位武將**:每位技能都已實作,支援身分局、百變模式與 ⚡ 連鎖牌
- **電腦夠聰明**:會推理身分、懂得配合隊友,不會偷看你的底牌
- **和朋友一起玩**:開房間、連線對戰、觀戰,斷線也能重連
- **段位排行**:打排位累積積分,解鎖頭像框、特效、成就
- **好看又順手**:20 種主題色,電腦、平板、手機都能玩,還有新手教學與卡牌圖鑑
- **免安裝環境**:下載、打開、開玩

## 下載
到 **[Releases](https://github.com/jkemusic/Threekingdoms/releases)** 下載最新版:

- **Windows**:下載 `.exe` 安裝檔,或 `.zip` 免安裝版
- **Mac**:下載 `.dmg`(第一次開啟請按右鍵 →「打開」)

## 卡牌圖片
線上伺服器 (<https://161.33.195.70.sslip.io/>) 的卡牌與武將使用原版美術加上自製插圖,直接開網頁就看得到。

安裝版 / 本機版不內附這些圖片 (原版美術有版權,本專案非營利、僅供朋友同樂),沒有圖片時以文字顯示,一樣能玩。
想在本機顯示圖片:選單「遊戲 → 開啟素材資料夾」,放入 `三國殺牌/` 與 `三國殺武將卡/` 後重新啟動。

## 和朋友連線
選單「遊戲 → 區網模式」,朋友在同一個網路用瀏覽器開 `http://<你的 IP>:8765/` 即可加入。
